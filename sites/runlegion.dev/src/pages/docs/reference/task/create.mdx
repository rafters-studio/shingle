## Usage

```bash
legion task create [OPTIONS] --from <FROM> --to <TO> --text <TEXT>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--from` | `` | Yes |  | Sender repository name |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--to` | `` | Yes |  | Target repository name |
| `--text` | `` | Yes |  | Task description |
| `--context` | `` | No |  | Additional context for the task |
| `--priority` | `` | No |  | Priority: low, med, high (default: med) [default: med] [possible values: low, med, high] |
