## Usage

```bash
legion recall [OPTIONS] --repo <REPO>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--repo` | `` | Yes |  | Repository name |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--context` | `` | No | "" | Current task context to match against (ignored with --latest) |
| `--limit` | `` | No | 5 | Maximum number of reflections to return |
| `--latest` | `` | No |  | Return most recent reflections instead of BM25 search |
