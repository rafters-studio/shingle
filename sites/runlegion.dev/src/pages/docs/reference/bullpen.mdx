## Usage

```bash
legion bullpen [OPTIONS] --repo <REPO>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--repo` | `` | Yes |  | Repository name (identifies who is reading) |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--count` | `` | No |  | Only show unread count instead of full bullpen |
| `--signals` | `` | No |  | Show only signals (structured coordination messages) |
| `--musings` | `` | No |  | Show only musings (natural language posts) |
