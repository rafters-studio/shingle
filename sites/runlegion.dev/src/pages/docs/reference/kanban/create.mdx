## Usage

```bash
legion kanban create [OPTIONS] --from <FROM> --to <TO> --text <TEXT>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--from` | `` | Yes |  | Who is creating the card |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--to` | `` | Yes |  | Which agent this card is assigned to |
| `--text` | `` | Yes |  | Card description |
| `--context` | `` | No |  | Additional context |
| `--priority` | `` | No |  | Priority: low, med, high, critical (default: med) [default: med] [possible values: low, med, high, critical] |
| `--labels` | `` | No |  | Comma-separated labels |
| `--parent` | `` | No |  | Parent card ID (for delegation chains) |
| `--source-url` | `` | No |  | Link to external issue (e.g., GitHub issue URL) |
| `--source-type` | `` | No |  | Source type (e.g., "github", "jira") |
