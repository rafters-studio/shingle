## Usage

```bash
legion reflect [OPTIONS] --repo <REPO>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--repo` | `` | Yes |  | Repository name(s), comma-separated (e.g., "kelex" or "platform,legion") |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--text` | `` | No |  | Reflection text (mutually exclusive with --transcript) |
| `--transcript` | `` | No |  | Path to session transcript JSONL file |
| `--domain` | `` | No |  | Domain tag for classification (e.g., "color-tokens", "auth") |
| `--tags` | `` | No |  | Comma-separated tags (e.g., "semantic-tokens,consumer,debugging") |
| `--follows` | `` | No |  | Link to a parent reflection ID to form a learning chain |
