## Usage

```bash
legion pr create [OPTIONS] --repo <REPO> --title <TITLE>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--repo` | `` | Yes |  | Repository name (resolves work source config from watch.toml) |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--title` | `` | Yes |  | PR title |
| `--body` | `` | No |  | PR body |
| `--base` | `` | No |  | Base branch (default: repo default branch) |
| `--head` | `` | No |  | Head branch (default: current branch) |
| `--draft` | `` | No |  | Create as draft |
| `--labels` | `` | No |  | Comma-separated labels |
| `--reviewer` | `` | No |  | Reviewer login (e.g., the review agent's GitHub account) |
| `--task` | `` | No |  | Kanban card ID to link (stores PR URL on the card) |
