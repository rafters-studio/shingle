## Usage

```bash
legion pr review [OPTIONS] --repo <REPO> --number <NUMBER>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--repo` | `` | Yes |  | Repository name (resolves work source config from watch.toml) |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--number` | `` | Yes |  | PR number |
| `--approve` | `` | No |  | Approve the PR |
| `--request-changes` | `` | No |  | Request changes on the PR |
| `--body` | `` | No |  | Review body text |
| `--comments` | `` | No |  | Path to JSON file with inline comments (GitHub API format) |
