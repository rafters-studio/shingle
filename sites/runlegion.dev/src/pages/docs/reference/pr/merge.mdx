## Usage

```bash
legion pr merge [OPTIONS] --repo <REPO> --number <NUMBER>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--repo` | `` | Yes |  | Repository name (resolves work source config from watch.toml) |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--number` | `` | Yes |  | PR number |
| `--strategy` | `` | No |  | Merge strategy: squash (default), merge, rebase [default: squash] [possible values: squash, merge, rebase] |
| `--keep-branch` | `` | No |  | Keep the branch after merging (default: delete) |
| `--task` | `` | No |  | Kanban card ID to transition to done |
