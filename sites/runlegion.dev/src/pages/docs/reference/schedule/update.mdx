## Usage

```bash
legion schedule update [OPTIONS] --id <ID>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--id` | `` | Yes |  | Schedule ID |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--cron` | `` | No |  | New cron expression |
| `--active-start` | `` | No |  | Active window start time (HH:MM UTC) |
| `--active-end` | `` | No |  | Active window end time (HH:MM UTC) |
