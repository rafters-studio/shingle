## Usage

```bash
legion done [OPTIONS] --repo <REPO> --text <TEXT>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--repo` | `` | Yes |  | Repository name |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--text` | `` | Yes |  | Description of what was completed |
| `--id` | `` | No |  | Card ID to mark as complete (optional) |
