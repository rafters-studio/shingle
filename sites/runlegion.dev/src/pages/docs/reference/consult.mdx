## Usage

```bash
legion consult [OPTIONS] --context <CONTEXT>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--context` | `` | Yes |  | Context describing the problem to search for |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--limit` | `` | No | 3 | Maximum number of reflections to return |
