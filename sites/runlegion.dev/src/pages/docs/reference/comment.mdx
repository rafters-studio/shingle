## Usage

```bash
legion comment [OPTIONS] --repo <REPO> --number <NUMBER> --body <BODY>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--repo` | `` | Yes |  | Repository name (resolves work source config from watch.toml) |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--number` | `` | Yes |  | Issue or PR number |
| `--body` | `` | Yes |  | Comment body |
