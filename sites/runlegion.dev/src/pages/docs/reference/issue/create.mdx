## Usage

```bash
legion issue create [OPTIONS] --repo <REPO> --title <TITLE>
```

## Flags

| Flag | Short | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--repo` | `` | Yes |  | Repository name (used to resolve work source config from watch.toml) |
| `--verbose` | `-v` | No |  | Show informational messages on stderr (quiet by default) |
| `--title` | `` | Yes |  | Issue title |
| `--body` | `` | No |  | Issue body |
| `--labels` | `` | No |  | Comma-separated labels |
| `--assignee` | `` | No |  | Assignee login |
