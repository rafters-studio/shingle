# Getting Started with Kelex

Kelex is a schema-first code generator in the Rafters Studio ecosystem. You
describe a schema; Kelex emits the code other tools render and run.

This page is a scaffold. Installation and first-run instructions land here as
the tooling stabilizes.

---

## Prerequisites

A working Node.js toolchain and a schema to generate from. Specific version
requirements are documented once the surface is pinned.
