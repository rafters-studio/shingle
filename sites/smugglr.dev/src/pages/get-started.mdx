<Section id="install" title="1. Install.">
    <P>Cargo is the recommended install. Pre-built binaries and a one-line installer script are on the GitHub releases page.</P>

    <Codeblock>{`cargo install smugglr`}</Codeblock>

    <P>Confirm it works:</P>

    <Codeblock>{`smugglr --version`}</Codeblock>
</Section>

<Section id="configure" title="2. Configure." tint>
    <P>Create a <code>config.toml</code> in your project directory: where the local SQLite lives, what the target is, and the target's connection details.</P>

    <Codeblock>{`local_db = "./local.db"

[target]
type = "d1"
account_id = "your-cloudflare-account-id"
database_id = "your-d1-database-id"
api_token = "your-d1-api-token"`}</Codeblock>

    <P>Any SQLite file works for <code>local_db</code>. <code>type</code> is <code>d1</code>, <code>sqlite</code>, or <code>plugin</code>; turso, rqlite, starbasedb, and sqlite-cloud all go through <code>type = "plugin"</code> with a profile <code>name</code>. See the <a href="/docs/configuration/">Configuration reference</a> for every option.</P>
</Section>

<Section id="dry-run" title="3. Dry-run.">
    <P>See what the push would do before doing it. Dry-run reads both sides, hashes, diffs, and reports. Nothing is written.</P>

    <Codeblock>{`smugglr push --dry-run`}</Codeblock>

    <P>The output tells you how many rows would push per table and whether they are new or updated. Run this as many times as you like. It is safe.</P>
</Section>

<Section id="push" title="4. Push." tint>
    <P>When the dry-run looks right, drop the flag.</P>

    <Codeblock>{`smugglr push`}</Codeblock>

    <P>smugglr pushes only the rows that actually changed, batched to respect the target's per-request SQL parameter limit. Transient HTTP failures retry with exponential backoff. Exit code 0 means success.</P>
</Section>
